# ✨ ToDo List Application

Современное, стильное и отзывчивое веб-приложение для управления ежедневными задачами, созданное на чистом **HTML5**, **CSS3** и **Vanilla JavaScript**.

---

## 🚀 Функциональность

- ➕ **Добавление задач:** Быстрое добавление через поле ввода или нажатие клавиши `Enter`.
- ✍️ **Зачёркивание и отметка выполнения:** Интерактивные кастомные чекбоксы и зачёркивание текста выполненных задач.
- 🗑️ **Удаление:** Удаление задач с плавной анимацией исчезновения.
- 📭 **Контроль пустого списка:** Информативная заглушка («Список задач пустой»), которая динамически скрывается при наличии задач.
- 💾 **Сохранение состояния (LocalStorage):** Все задачи автоматически сохраняются в браузере и остаются доступными после перезагрузки.
- 📊 **Счётчик задач:** Подсчёт общего числа задач и оставшихся невыполненных.
- 🧹 **Очистка выполненных:** Быстрое удаление всех завершённых дел одной кнопкой.

---

## 🛠️ Стек технологий

- **HTML5:** Семантическая и доступная разметка (`ARIA`-атрибуты, семантические теги).
- **CSS3:** Тёмная тема с эффектом Glassmorphism (матовое стекло), адаптивная вёрстка под смартфоны и ПК, CSS-анимации.
- **JavaScript (ES6+):** Чистый Vanilla JS без сторонних библиотек и фреймворков.

---

## 📦 Быстрый запуск

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/IsagiYoichiEgo/Todo-list-.git
   ```
2. Откройте файл `index.html` в любом современном браузере.

---

## 🌐 Развертывание на GitHub Pages

1. Перейдите в **Settings** репозитория на GitHub.
2. В левом меню откройте **Pages**.
3. В секции **Build and deployment** выберите источник **Deploy from a branch**.
4. Укажите ветку `main` и папку `/ (root)`, затем нажмите **Save**.
5. Приложение станет доступно по адресу:
   `https://isagiyoichiego.github.io/Todo-list-/`
